# Media assets

Place assets here when ready, for example:

- `logo.svg` or `logo.png` — brand mark
- `featured-01.jpg` — featured still image
- `featured-02.mp4` — featured video

Then update [`js/content.js`](../../js/content.js) with the corresponding path, such as `/assets/images/logo.svg` or `/assets/images/featured-01.jpg`.

Remote HTTPS image and MP4 video URLs work too. Keep video files web-optimized; for larger videos, use a dedicated video host and place its direct MP4 URL in `src`.
